# ছোট্ট বর্ণমালা

বাংলা বর্ণমালা শেখার একটি সহজ Android অ্যাপ, ২–৪ বছর বয়সী শিশুদের জন্য। অক্ষরে স্পর্শ করলে বাংলা উচ্চারণ এবং উদাহরণ শব্দ শোনাবে।

## Build
GitHub Actions automatically builds a debug APK on every push to `main`. Download it from the Actions run's Artifacts section.

## Voice
The app uses the Bengali voice installed on the Android device through Android TextToSpeech. Bengali voice data may need to be installed in device settings.
